## MLFlow remote tracking server using DagsHub

In this video, we are going to perform the following steps:

1. Login into DagsHub  
2. Create a new GitHub repository  
3. Push our code to GitHub  
4. Connect the GitHub repository with DagsHub  
5. Set Tracking URI: In your ML code, set the tracking URI to point to your DagsHub repository’s MLflow endpoint.  
6. Log Experiments: Run your experiments as usual, and MLflow will log everything remotely to DagsHub.  
7. View Results: Go to your DagsHub repository to see a dashboard of all your logged runs, complete with metrics, parameters, and any uploaded artifacts.

- Open dagshub.com and login using github account.
- create new repo **mlflow_exp_dagshub**, clone the repo in the local and push the updated code
- Establish connection between dagshub and github with selected privilages.
```sh
pip install mlflow
pip install dagshub
```
